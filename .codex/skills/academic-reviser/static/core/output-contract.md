# Reviser Output Contract

## Verification Status

Output follows `skills/shared/schemas/verification-report.md`.

**Debt types** (8):
- `prose_debt`, `section_contract_debt`, `citation_debt`, `evidence_debt`, `figure_debt`, `protocol_debt`, `result_debt`, `rationale_debt`

## Deliverables

### full-section-review / targeted-review

- Section Critique
- Revised Draft (must absorb fixes)
- Verification Status (`passed`/`failed`/`blocked`)

### cross-section-review

- Cross-section consistency report
- Flagged conflicts

### verification-only

- Verification Status only (no re-review)

### targeted-evidence-mode

- `evidence_debt: open|closed`
- `evidence_issues` list
- Do not modify prose

### mock-reviewer-package

- 3 reviewer-style reports + cross-review synthesis
- Optional, does not replace Verification Status
- Cannot invent reviewer identities or unprovided evidence
