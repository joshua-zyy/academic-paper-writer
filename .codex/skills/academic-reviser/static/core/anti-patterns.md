# Reviser Anti-Patterns

| 模式 | 问题 | 正确做法 |
|------|------|---------|
| 跳过证据先修风格 | 只改措辞不改内容债务 | 严格证据→论证→风格顺序 |
| 假修改 | 输出 Revised Draft 但内容未真正吸收批判 | 每项批判必须对应具体修改 |
| 善意假设 | 因草稿篇幅长假设足够可信 | 每个 claim 必须验证证据支撑 |
| 美化包装 | 用漂亮 prose 掩盖 related work 薄或 evidence gap | 标记 section_contract_debt 和 evidence_debt |

## Self-Deception Signals

主动检查并标记为 failed：
- 只修措辞不修证据
- 用长度代替可信度
- 用连接词维持表面连贯而非深层逻辑
- 把结构债务伪装成流畅 prose
