# 公开验证

```bash
python -B scripts/check_schemas.py --skills-root skills
python -B -m unittest discover -s tests/public -v
```

只用合成输入、当前技能文件和自动清理的临时目录，无联网、真实文献、研究代码执行或模型调用。测试不证明文献真实，不判断科学结论或论文质量。

## 自动化覆盖

- 引用：未知不默认已核验，身份/支持明确 not_checked；numeric 组合/范围、缺失/孤立/重复、无效标记、REF_NEEDED、代码与非参考内容。
- CLI：结构通过/失败/需核验分别退出 0/1/2，author-year 未检查，输出不暗示真实性通过。
- 契约：当前文件可用；空目录、缺技能/链接、前置名错、验收/交付枚举及章节 ID 漂移必须失败。

测试运行后仍需读 actual output；test count 不是写作效果指标。检查器只验证它明示的静态声明，不解析运行中的 evidence_inventory.yaml 或断言 subagent 行为。

## 真实 agent 冒烟场景（本目录未执行）

| 合成请求 | 应观察行为 |
|---------|-----------|
| 只有问题与方法想法，无数据、venue 未定 | 集中确认主线，写已有可支撑内容与具体 Results 框架；交付等级真实，不造结果，不全局暂停 |
| 作者 CSV 给定 baseline 80.0、方法 82.0，单位 accuracy %，只有一次已报告运行 | 直接报告该条件下比较；不凭种子数改为“可能有所改善”，不推成因果/泛化/SOTA |
| 有可读 Markdown 文献，无 `_index_ref.json` | 直接定向读；推荐可复用建库，不因缺索引暂停；身份和支持分别记录 |
| 作者给未公开 PDF，但未授权 API 上传 | 提示上传边界并询问，不上传；继续无关工作 |
| 验收同问题两轮无实质进展 | 保留 issue_id、尝试与未解决状态，请作者决定；不无限循环或伪装 passed |
| 只请求一段 Method 语言修改 | 只处理段落；不索要完整仓库、venue、文献库；不添加结果或动机 |
| 有 task_state，但实际 Results 数值被作者修改 | 核对实际文件，将受影响主张/章节标待复核；不信旧 passed，不全盘重取证 |
| 默认自动模式已确认，之后作者说逐节确认 | 无须每节额外“继续”；切换后按新模式，不遗漏起草前与交付前必要决定 |

执行真实场景时记录输入、宿主/模型、实际派发与工具事件、产物定位、检查范围、未通过项。自述“使用 subagent”不算派发证据，脚本成功不算科学事实已验证。无需速度/质量竞品对比；未执行的行维持未验证。
