# 文献取证原则

本地优先、按论点需要搜索，不按篇数与查询配额生产引用。复用已核对来源，定向补缺。

启动建议 MinerU 建库，不能把索引不存在判定为内容不可读。实际需要原文却不可读时保留未核验状态，不暂停其他文献或整篇框架。

身份确认优先出版方、官方 proceedings、DOI/arXiv/权威索引等真实打开的来源。原文支持另记录具体片段和定位；子代理推断不是该论文已证实内容。摘要仅支持其实际陈述，不冒充全文读取。

未知默认 UNVERIFIED；冲突保留。Crossref 没查到不等于文献不存在。候选检索列表可以无正文 marker，正式 References 则只收正文实际引用条目。

Exemplar 按写作需要学习组织，不强制每节额外固定数量。主笔决定采用文献，subagent 不写正文。
