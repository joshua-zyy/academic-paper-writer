# 引用检索与核验

## 1. 目标与本地准备

从当前论点、章节、作者种子文献提取关键词，复用已有映射。全文任务主动建议 MinerU PDF→MD 建库，脚本以当前 skill 实际路径调用，--type ref/style；告知 API 上传与敏感材料授权。

已有 `_index_ref.json` 优先筛选；无索引时按文件名与内容搜索，不全库读入。可读 MD/PDF 直接用，元数据任务不要求全文，转换失败只影响相关判断。

## 2. 定向检索

优先本地命中，再补公开来源。问题、方法、基线、近期工作等查询模板见 search-strategy.md，按缺口选择而非每次全部执行。独立阅读并行，按论文长度与工具能力分批，不强制三个 reader。

本地内容已够支撑仍需身份来源核对；网络不可用明确边界。没有可靠结果列具体 seed/检索建议，已有框架继续，不造假引用。

## 3. 身份与支持

核对标题、作者顺序、年份/版本、venue、DOI/arXiv 的实际来源，保存 identity_sources、checked_fields 和冲突。分别阅读要支撑的原文片段，记录 source_locator、source_excerpt、支持状态与范围。

支持复杂方法比较和解释性分析需读相关正文/图表；摘要够支撑的简单背景注明 abstract_only。看不到的全文不推断内容，图像不可读不猜数值。

## 4. 采用与复用

reader 只提炼，主笔决定是否采用。partial 支持只写其范围，contradicted 不能当支持，not_checked 留待补。Exemplar 仅用于组织学习，非来源权威或引文配额。

正式 References 与正文 marker 一一对应；候选留来源记录，未采用不混入正式书目。min_citations 报建议与实际值，不循环搜索凑数。

## 5. 最后检查

citation_audit.py 检查数字格式结构；身份与内容支持仍由来源比对完成。局部任务不要求全稿检查，修引用仅复核相关段落与编号映射。
