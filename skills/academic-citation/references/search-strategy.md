# 定向检索策略

全文按研究问题覆盖必要背景、直接相关方法、实际比较对象和近期代表工作。局部任务只检索目标主张；停止依据是支持覆盖与明确缺口，不是文献/查询数量。

| 缺口 | 查询模板 |
|---|---|
| 问题背景 | `<task> review`、`<domain> <task> survey` |
| 方法定位 | `<method family> for <task>`、`<architecture> <task>` |
| 实际基线 | `<dataset> <baseline>`、`<task> benchmark` |
| 近期工作 | `<task> <current_year>`、`<method family> recent` |
| 解释性分析 | 观察对象+解释机制+领域关键词，核对对象与条件 |
| exemplar | 同任务/模态的实际论文，阅读相应章节组织 |

本地先筛选，来源已读就复用。命中不足换同义词或上级领域概念；网络/全文不可用说明具体缺口，不能无限检索凑数。

身份核对优先官方出版/proceedings、arXiv 版本与权威索引；搜索摘要卡片和博客只当线索。Exemplar 提炼组织职责与比较方式，不复制句子、不冒充官方政策，也不强制篇数。
