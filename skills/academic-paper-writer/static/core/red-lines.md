# 禁止事项

- 编造数据、文献、方法、运行记录、作者意图、核验或验收结果。
- 子代理起草或修订正文、覆盖正式稿；主 agent 修改研究代码、配置或原始数据。
- 把作者想法写成已观察结果，把身份已确认写成引用支持已确认。
- 擅自新实验、重训、改协议；无授权重算或上传敏感 PDF。
- 以 min_citations、venue 未定、索引不存在、可选消融缺失阻塞所有写作。
- 把框架或待补章节包装成完整稿，把作者接受缺口等同问题已修复。
- 为通过验收而加空话、凑段落、反复削弱语气或删除真实矛盾。
- 把审查流程说明混入正文，维护多份章节级 References，恢复时切换论文根目录。
