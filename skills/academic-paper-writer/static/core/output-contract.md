# 内容稿输出契约

默认输出根目录 `./academic-paper-writer/paper-drafts/`；复用同一论文任务的显式路径。

## 核心产物

- `paper_draft.md`：实质正文与必要框架；唯一文末 References；末尾统一待补清单。清单列位置、缺什么、建议材料、能支撑什么。
- `section_blueprint.md`：已确认主线、章节职责及来源/缺口。
- `evidence_inventory.yaml`：合并事实、来源、作者材料、冲突及缺口；附引用身份记录和引用—主张映射，不强制空表。
- `task_state.yaml`：仅全文/多节持续任务使用，记录已确认选择、章节进度、未解决问题与下步；格式见 `references/workflow-step-9.6-12.md`。
- 按需：`venue-brief.md`、`figures/` 数据图、`figures/codes/` 绘图代码与图注。架构图只检查作者材料或记录人工需求。

## 完成条件

已处理请求范围；正文与框架区分；引用与数据来源可回查；章节及全文适用检查已执行并记录边界；未解决项与正文同步；无虚构或自相矛盾的完成宣称。

交付等级使用共享验收契约的 usable_draft / partial_draft / structured_outline。缺材料不阻塞整体交付，不得将未验收部分说成已通过。min_citations 仅建议，不是完成条件。

独立段落/章节任务可直接返回所需文本；用户要求文件时更新指定稿件并说明受影响范围，不强制创建全文产物。完整稿默认写文件，对话只给简短进度、路径和关键问题。

不默认交付 Word、LaTeX 模板、编译 PDF、投稿信或提交文件包。
