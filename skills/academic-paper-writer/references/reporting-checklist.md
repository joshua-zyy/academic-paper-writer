# CS/AI/ML 协议描述检查

按实际研究与目标官方要求适用，不是额外实验配额，也不是方法学评分。

| 项目 | 需要说明的已有信息 |
|---|---|
| 数据 | 名称、来源、样本/受试者数、实际划分、纳入排除和预处理 |
| 训练与选择 | 优化器、关键超参数、停止/模型选择、实际种子和环境 |
| 指标 | 定义、单位、聚合、评估集、阈值等关键口径 |
| 比较 | 基线来源、实际数据/协议条件、表格来源 |
| 分析 | 已做的消融/解释/统计方法及对应结果；不存在不假装已做 |
| 资源与合规 | 作者已有硬件、耗时、数据许可/伦理信息；正式要求需要时指出缺项 |

未提供项列具体作者输入建议；不默认多种子、近期基线、外部测试或统计检验必须新增。不把“协议写清楚”变成实验优劣判定，不编伦理许可或运行结果。
