# 按需图表与图文一致性

图必须服务具体论点，不要求每节配图或全文结束后强制批量绘图。

## 生成前

确认用途、源数据/证据 ID、面板含义、单位/聚合/条件、误差含义及分配输出路径。不可得的统计量不猜；重算统计另需限定授权。架构/框架/流程/机制图由作者提供，可记录需要展示的实际模块与图注，不自动绘图或生成图片 prompt。

## 数据图

真实数据可用且已授权在指定目录生成图时，调用 academic-figure。默认 Python + matplotlib 可编辑 SVG，保留可复现脚本与绘图源数据；避免修改原始数据。无运行条件交付代码或 blueprint，并标 not_checked，不能算已生成图。不自动安装依赖、不自行批量执行不明脚本。

建议脚本保存到当前 paper_root/figures/codes/，不是假定所有任务固定目录。字体 svg.fonttype='none'，清晰单位、适当轴范围、色盲/灰度友好；结构按论证调整，不强套某种 archetype。

## 验收

实际打开生成图，核对数字、单位、条件、误差和 caption/正文。来源与图片对应、坐标不失真、文本可读、输出真实可用。未执行/未看图如实记录；缺图给具体补充项，独立章节继续，不声称投稿包完成。
