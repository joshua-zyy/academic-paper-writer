# 全文编排导航

一次启动持续产出内容稿；内部逐节推进不等于要求作者逐节催促。主 agent 唯一写作，职责遵循共享输出边界。

| 阶段 | 读取 | 产物 |
|---|---|---|
| 准备与首轮探查 | workflow-step-0-7.md | 已确认输入、证据记录、缺口 |
| 主线与写作 | workflow-step-8-9.5.md | 作者确认的主线、正文/框架、数据图 |
| 验收与交付 | workflow-step-9.6-12.md | 适用检查、修订、内容稿等级、待补清单、恢复状态 |

阶段之间只传递必要证据与当前产物，不把全部历史上下文复制给每个子代理。对工作产物做检查，不以文件存在、任务勾选或自评分证明论文质量。

局部任务直接进入相关阶段，不强制全文准备。按需调用 academic-citation、academic-experiments、academic-figure、academic-venue-research；academic-polishing 主笔内化；academic-reviser 一个验收角色。排版技能不在默认链路。

作者确认点：起草前主张与主线、交付前重大未解决项及等级。中途仅必要事实确认、核心主张变化、执行授权或高成本补证决策；可以继续独立部分。
