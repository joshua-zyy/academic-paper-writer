# 润色原则

保持事实、数字、术语、引用和作者意图。改善实际逻辑衔接，不仅替换连接词；删除空泛评价、流程说明、重复和无内容展望。

有支持的陈述直接说，不按 Strong/Medium/Weak 将整个研究一律降调。描述模块“作为聚合器”不是因果功效主张；多种子不等于分布鲁棒性；“据我们所知”不补新颖性证据。

必要局限在 Discussion 适度集中；其他章节描述实际范围即可，不反复追加“尚不能推断……”或泛化免责。超出事实的主张仍须具体修正，不删会改变结论的边界。

独立章节请求允许段落重排与局部结构重写，不因旧 section_contract_debt 禁止改写。信息不足的部分保留明确缺口；不能靠更流畅的语言造方法、结果或因果。

Method 按作者意图与实际操作组织，标准组件简写，核心机制清楚；不强制每模块一套问题/公式/收益/代价。主张范围判断详见 references/claim-strength.md。
