# Style Analysis Guide

本文件包含写作风格分析的详细指南。

---

## 分析内容

### 1. 论文结构偏好

**Introduction**：
- 长度：平均段落数 / 页数
- 组织方式：常见结构（如背景→问题→贡献→论文结构）

**Related Work**：
- 位置：独立章节 / Method 内 / Introduction 内
- 组织方式：按技术路线 / 按任务 / 按限制类型

**Method**：
- 详细程度：高 / 中 / 低
- 子章节组织方式

**Experimental Setup**：
- 详细程度：高 / 中 / 低
- 包含内容（数据集、基线、评估指标等）

**Discussion 和 Conclusion**：
- 写法：总结型 / 展望型 / 混合型

### 2. 写作风格偏好

**语气**：
- 正式 / 半正式 / 非正式
- 主动语态 / 被动语态

**用词偏好**：
- 技术术语多 / 少 / 适中
- 常用表达方式

**句式结构**：
- 长句多 / 短句多 / 混合
- 复合句使用频率

**段落长度**：
- 长段落 / 短段落 / 混合
- 每段平均句子数

### 3. 引用密度

**引用数量**：
- 平均每篇论文的引用数量
- 各章节引用密度

**引用格式**：
- 数字格式（如 [1]）
- 作者-年份格式（如 Vaswani et al., 2017）

**引用位置**：
- 引用在句子中的位置
- 引用与正文的融合方式

### 4. 图表使用偏好

**图表数量**：
- 平均图表数量
- 各章节图表分布

**图表类型**：
- 架构图 / 数据图 / 混合
- 常见图表类型

**图表说明**：
- 详细程度：高 / 中 / 低
- 说明格式

### 5. 各个部分的写法

**Abstract**：
- 长度：平均字数 / 句子数
- 结构：背景→问题→方法→结果→贡献
- 信息密度：高 / 中 / 低

**Introduction**：
- 背景介绍方式
- 问题陈述方式
- 贡献总结方式
- 论文结构介绍方式

**Method**：
- 详细程度
- 公式使用频率
- 算法描述方式

**Experiments**：
- 结果展示方式
- 分析深度
- 讨论方式

## 分析方法

### 本地文献库分析

1. 读取本地风格参考文献库中的论文
2. 选择 3-5 篇代表性论文
3. 对每篇论文进行结构分析
4. 汇总分析结果，提取共性特征

### 开放获取论文分析

1. 通过 webfetch 访问期刊官方网站
2. 查找开放获取的论文（如 Open Access 论文）
3. 通过 arXiv、OpenReview 等平台获取预印本
4. 对获取的论文进行结构分析

### 基于摘要分析

1. 通过学术搜索引擎获取论文的摘要
2. 基于摘要和已知信息进行风格分析
3. 标注分析方法为"基于摘要分析"
