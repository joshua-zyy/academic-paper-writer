# Style Analysis Guide

本文件包含写作风格分析的详细指南。

---

## Step 0: 筛选与研究主题最接近的同期论文（强制前置步骤）

在进行任何风格分析之前，**必须**先从目标期刊筛选 3-5 篇与项目研究主题最接近的论文：

1. 从 local 风格文献库（`local_style_md_dir`）或通过 webfetch 获取目标期刊最新（近 2 年）论文列表
2. 使用传入的 `project_keywords`（5-8 个关键词：任务领域、方法家族、数据集/模态等）筛选候选论文：至少匹配 2 个关键词的论文进入候选
3. 从候选论文中按以下优先级选择 3-5 篇进行分析：
    - 优先：任务相同 + 方法家族相同
    - 次选：任务相同 + 方法家族不同
    - 补充：任务不同 + 方法家族相同（观察方法迁移风格）
4. 对每篇入选论文，标注相似度原因：共享任务、共享方法、共享数据集/模态中的哪几项
5. 若无法从同期刊找到足够相似论文 → 扩展搜索范围至同领域顶会/顶刊，但标注 `source_venue: different`

## 分析内容

### 1. 论文结构偏好

**Introduction**：
- 长度：平均段落数 / 页数
- 组织方式：常见结构（如背景→问题→贡献→论文结构）

**Related Work**：
- 位置：独立章节 / Method 内 / Introduction 内
- 组织方式：按技术路线 / 按任务 / 按限制类型

**Method**：
- 详细程度：高 / 中 / 低
- 子章节组织方式

**Experimental Setup**：
- 详细程度：高 / 中 / 低
- 包含内容（数据集、基线、评估指标等）

**Discussion 和 Conclusion**：
- 写法：总结型 / 展望型 / 混合型

### 2. 写作风格偏好

**语气**：
- 正式 / 半正式 / 非正式
- 主动语态 / 被动语态

**用词偏好**：
- 技术术语多 / 少 / 适中
- 常用表达方式

**句式结构**：
- 长句多 / 短句多 / 混合
- 复合句使用频率

**段落长度**：
- 长段落 / 短段落 / 混合
- 每段平均句子数

### 3. 引用密度

**引用数量**：
- 平均每篇论文的引用数量
- 各章节引用密度

**引用格式**：
- 数字格式（如 [1]）
- 作者-年份格式（如 Vaswani et al., 2017）

**引用位置**：
- 引用在句子中的位置
- 引用与正文的融合方式

### 4. 图表使用偏好

**图表数量**：
- 平均图表数量
- 各章节图表分布

**图表类型**：
- 架构图 / 数据图 / 混合
- 常见图表类型
- 若 venue 偏好架构图，后续只记录为 `manual_figure_needed`；`academic-figure` 不自动绘制架构图。

**图表说明**：
- 详细程度：高 / 中 / 低
- 说明格式

### 5. 各个部分的写法

**Abstract**：
- 长度：平均字数 / 句子数
- 结构：背景→问题→方法→结果→贡献
- 信息密度：高 / 中 / 低

**Introduction**：
- 背景介绍方式
- 问题陈述方式
- 贡献总结方式
- 论文结构介绍方式

**Method**：
- 详细程度
- 公式使用频率
- 算法描述方式

**Experiments**：
- 结果展示方式
- 分析深度
- 讨论方式

### 6. 逐节深度分析（从 3-5 篇相似论文中提取共性）

对 Step 0 筛选出的 3-5 篇相似论文，逐节执行深度分析，提取每节的共性规律、典型短语和反例。

#### 6.1 Introduction 深度分析

对每篇入选论文的 Introduction 进行逐段解构，提取以下信息：

1. **段落级逻辑链**：用一句话概括每个段落的论证功能（如 "段1：领域重要性 + 数据规模增长事实"、"段2：现有方法两个方向的共同假设"）
2. **逻辑展开模式**：归纳入选论文的共同叙事结构
   - 例："领域价值声明 → 现有方法的共同假设 → 关键限制 → 本文突破 → 贡献概述 → 论文组织"
3. **问题 gap 的搭建方式**：现有论文是如何从"已有工作"自然过渡到"gap"的？
   - 是否使用"然而"/"但是"类转折？
   - gap 是否通过引用具体数字或事实支撑？
4. **贡献陈述的语言模式**：收集 3-5 篇论文中表述贡献的典型句式
   - 例："To address this gap, we propose..."、"In this work, we..."、"We make the following contributions:"
5. **段落过渡规律**：相邻段落之间的连接方式（递进/对比/因果/举例）
6. **关键词汇与短语**：提取入选论文 Introduction 中反复出现的高频关键短语（如 "recent advances"、"remains a challenge"、"in this paper"）
7. **反例识别**：标注入选论文中不符合共性的异常段落/结构

#### 6.2 Related Work 深度分析

1. **工作簇分组逻辑**：入选论文按什么维度组织 Related Work？
   - 维度：技术路线 / 任务类型 / 方法家族 / 时间演进 / 限制类型 / 混合
2. **每簇的论述结构**：每簇是否遵循 "共享 idea → 代表工作 → 能力 → 限制 → 与本文的关系" 模式？
3. **聚类粒度**：每篇论文的 Related Work 分为几个工作簇？每簇平均引用几篇？
4. **区别点表达方式**：论文如何精确表达"本文与最接近工作的区别"？
   - 例："Unlike [15] which uses static graphs, our method..." "While [15] focuses on..., we..."
5. **引用密度模式**：每段平均引用数？哪些位置引用密集（合成段落）？哪些位置稀疏（描述性段落）？
6. **典型句式**：收集工作簇介绍、代表工作引用、区别陈述的典型句式
7. **反例**：标注不符合共性的部分

#### 6.3 Method 深度分析

1. **数学形式化深度**：入选论文 Method 中的公式密度（公式数 / 页数）？公式是推导型还是定义型？
2. **架构叙事顺序**：论文是如何从 overall framework 逐步展开到 core module 的？
   - 常见顺序："整体架构 → 符号定义 → 逐模块展开 → 训练目标"
3. **设计理由表述方式**：入选论文如何解释"为什么这样设计"？
   - 例："Since the temporal correlations of EEG signals vary across subjects..." "To capture the long-range dependencies..."
4. **模块边界描述**：入选论文如何界定每个模块的输入/输出/边界？
5. **改进点/创新点的位置**：Narrative 中的创新点通常出现在哪个位置？如何与新模块的 description 融合？
6. **公式排版与命名规范**：使用的记号风格（粗体/斜体/手写体）、维度符号（d/n/T/N 等）
7. **典型句式与常见标识符**：收集 Method 中常见的描述句式
   - 模块引入："We design a... to..."、"The core of our approach is..."
   - 设计理由："The motivation behind this design is..."
   - 边界说明："Note that..."、"It is worth noting that..."

#### 6.4 Experiments 深度分析

1. **实验叙事结构**：入选论文的实验部分如何组织？
   - 常见："实验设置（数据集+基线+指标）→ 主结果对比 → 消融实验 → 可解释性/案例分析 → 讨论"
2. **数据集描述模式**：论文如何描述数据集（统计信息、来源、划分方式）？
   - 描述粒度：样本量、类别分布、输入维度、预处理步骤
3. **基线选择与介绍**：入选论文如何选择和介绍基线方法？是否涵盖经典方法和最新方法？
4. **结果报告方式**：最优指标是 bold 体还是单独标注？是否报告标准差/置信区间？
5. **消融实验设计**：入选论文通常做几类消融？消融实验的假设陈述方式？
6. **结果解释的语言模式**：如何从数字过渡到分析？
   - 例："As shown in Table 2, our method achieves..." "The improvement can be attributed to..."
7. **图表说明风格**：图标题/表标题的详细程度、图注是否独立可读？

#### 6.5 Dataset 描述模式（若适用）

1. **数据集统计信息格式**：样本数、类别数、维度等如何呈现（文字 vs 表格）
2. **数据来源与引用**：公共数据集引用方式，私有数据集描述方式
3. **预处理步骤描述深度**：是否详细到参数级别（滤波器参数、标准化方法）？

## 分析方法

### 本地文献库分析

1. 读取本地风格参考文献库中的论文
2. 选择 3-5 篇代表性论文
3. 对每篇论文进行结构分析
4. 汇总分析结果，提取共性特征

### 开放获取论文分析

1. 通过 webfetch 访问期刊官方网站
2. 查找开放获取的论文（如 Open Access 论文）
3. 通过 arXiv、OpenReview 等平台获取预印本
4. 对获取的论文进行结构分析

### 基于摘要分析

1. 通过学术搜索引擎获取论文的摘要
2. 基于摘要和已知信息进行风格分析
3. 标注分析方法为"基于摘要分析"

## 输出格式

按照 `references/venue-brief-template.md` 格式输出写作风格备注部分。
