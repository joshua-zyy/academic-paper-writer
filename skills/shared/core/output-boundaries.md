# 输出与角色边界（权威规则）

## 编排调用

- 主 agent 是唯一论文作者，负责主线、正文、改稿、合并和最终文件写入。
- 探查 subagent 只返回事实、来源、冲突、缺口与建议；不得输出 Results/Setup 等候选正文。
- 验收 subagent 只返回问题及修复完成条件，不输出 Revised Draft，不模拟审稿人，不评判录用或创新性。
- academic-polishing 由主 agent 内化执行，不派发第二作者。
- academic-figure 可在明确分配的输出路径创建绘图代码和图表；主 agent 核对后引用，子代理不得编辑正文。
- 不修改项目源代码、配置、原始数据或既有实验产物。派发任务注明读范围、允许产物和禁止操作。

## 独立调用

用户直接请求润色、改写、绘图或排版时，当前执行 agent 可按任务编辑所请求的文本或产物。无需整篇准备流程。验收技能仍只检查，不自动改写；实际改稿使用 polishing 或 writer。

文件输出使用任务指定路径；默认论文目录为 `./academic-paper-writer/paper-drafts/`。不覆盖无关文件。一个论文任务保持同一输出根目录，恢复时检查实际文件，不从最近目录猜任务身份。

## 执行授权

读取和核对已有材料可自动进行。重算指标、统计检验需要作者预先限定输入、方法和预算的授权。新实验、重训、改变评估协议需单独批准。不得因目录路径、默认模式或失败恢复而获得执行权限。

MinerU API 会上传 PDF；启动建议建库时告知，上传未公开或敏感材料需明确授权。不得把 token 写进产物或报告。
