# Evidence Policy

This file defines cross-skill evidence semantics for the academic skill suite.

## Evidence Types

| Type | Meaning | May support paper claims |
|---|---|---|
| `newly_run` | Evidence generated by a command run in the current working session | yes |
| `preexisting_artifact` | Existing local artifact such as logs, CSV files, checkpoints, tables, or prior verified outputs | yes, with source and limitation notes |
| `user_claim` | User-provided statement without independently inspected evidence | no |

## Rules

1. Treat `newly_run` and `preexisting_artifact` as usable evidence only when their source path, command, or provenance is recorded.
2. Treat `user_claim` as context for investigation, not as verified evidence.
3. Weaken, freeze, or mark unsupported claims instead of making them sound more certain.
4. Preserve placeholders when evidence is missing; do not delete placeholders unless real evidence replaces them.
