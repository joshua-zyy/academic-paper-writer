# 按章节验收

| 章节 ID | 适用检查 |
|---|---|
| introduction | 问题与现有工作能导出本文主线，贡献与主体一致；外部背景有匹配引文，不空泛夸大缺口 |
| related_work | 按相关比较维度综合，不只列论文；描述与原文相符，不虚构竞争方法缺陷 |
| method | 数据流、符号、关键操作、输入输出、作者设计意图清楚；与材料一致，不强制每模块配图或公式 |
| experimental_setup | 实际数据与划分、预处理、训练/选择、指标和比较条件交代清楚；缺项不按常识补 |
| results | 数字、口径、表图与正文一致；关键观察有数据，不编显著性，不要求可选消融齐全 |
| discussion | 解释与结果及文献吻合，观察与假设区分；集中适度的局限，不泛泛防御或展望 |
| conclusion | 总结已有正文，不引入新数值、方法或结论 |
| abstract | 主体问题、方法和已有主要发现准确一致；缺核心材料可框架化，不虚构完整摘要 |

局部段落只查相关项；其他列 na。当前材料不足形成框架时标明检查边界与作者输入，不以字数、段数、引用数判定失败。问题字段及 verdict 使用共享验收契约。
