# 定向盘点

先读取已有证据记录，只补与 question 相关的材料。

| 来源 | 提取 |
|---|---|
| 作者表格/笔记/消息 | 结果数值、方法说明、设计意图；分别记录内容性质 |
| config、运行脚本、日志 | 实际配置、数据路径、训练/评估入口、运行版本 |
| CSV/JSON/结果表 | 指标定义、单位、聚合粒度、划分、模型/变体、数值 |
| checkpoint | 文件存在与关联记录；仅存在不证明指标，不默认加载执行 |
| 图表与绘图脚本 | 源数据、筛选条件、图注口径 |

输出共享契约的事实、冲突和缺项。代码中的设置与最终日志不一致，保留双方定位并核对实际运行版本。没有原始数组不自动否定作者报告结果。
