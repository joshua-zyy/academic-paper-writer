# 协议描述与事实冲突

本技能不进行审稿人级的方法学评价。检查稿件所需的协议事实能否交代清楚：数据来源、划分单位/比例、预处理、训练设置、模型选择、指标定义、比较条件、已报告的不确定性及消融设置（存在时）。

只报告实际缺项或矛盾。例如稿件称 subject-level split，配置/日志称 sample-level split：定位两者，核对最终运行版本，仍不明请作者确认。不因为缺外部测试、多种子或某个基线就判研究无效，也不强制加新实验。

已有信息足以限定当前描述时正常陈述；必要局限交主笔在 Discussion 适度处理，不把每个观察改成防御语气。需要更多材料时列建议及其写作用途，不起草正文。
