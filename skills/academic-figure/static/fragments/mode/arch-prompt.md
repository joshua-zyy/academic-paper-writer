# Mode: arch-prompt

Use this mode when the user wants a structured prompt for an external image-generation or design tool.

## Workflow

1. Extract confirmed components, data flow, and connection semantics.
2. Identify unconfirmed items and preserve them as verification notes.
3. Produce a tool-agnostic prompt without tool-specific flags or rendering parameters.
4. Keep labels short and move detailed explanation into caption guidance.

Open `references/workflow-arch-prompt.md` and `references/architecture-prompting.md` when prompt structure or wording detail is needed.
